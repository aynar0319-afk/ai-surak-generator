# 📚 Оқу материалдары бойынша AI сұрақ генераторы

Бұл жоба оқу материалдары (PDF және TXT) негізінде жасанды интеллект (Google Gemini) көмегімен 5 қиындық деңгейінде тест және ашық сұрақтарды автоматты түрде құрастыратын веб-қосымша болып табылады.

## 🚀 Негізгі мүмкіндіктер
- **Құжаттарды жүктеу:** Бірнеше PDF және TXT файлдарынан мәтінді автоматты түрде алу.
- **Тақырыптарды анықтау:** AI арқылы оқу материалының негізгі бөлімдері мен тақырыптарын табу.
- **5 қиындық деңгейі:** 1 (Өте жеңіл) деңгейінен 5 (Өте қиын) деңгейіне дейін сұрақтар құрастыру.
- **Интерактивті тестілеу:** Тест (A, B, C, D) және ашық сұрақтарға жауап беру, дұрыстығын тексеру және түсіндірме алу.
- **AI сапа бағалауы:** Пайдаланушының барлық жауаптарының сапасын AI арқылы кешенді талдау.
- **Дерекқор (SQLite):** Құрастырылған сұрақтарды сақтау, өңдеу, өшіру және JSON форматында жүктеп алу.
