# 📚 Оқу материалдары бойынша AI сұрақ генераторы

## 📖 Жоба туралы

Бұл жоба оқу материалдары (PDF және TXT) негізінде жасанды интеллект (Google Gemini) көмегімен тест және ашық сұрақтарды автоматты түрде құрастыратын веб-қосымша болып табылады.

Жүйе пайдаланушы жүктеген оқу құжаттарынан мәтінді алады, оны өңдейді және негізгі тақырыптар бойынша әртүрлі қиындық деңгейіндегі сұрақтарды генерациялайды.

Жобаның негізгі мақсаты — студенттердің білімін тексеруді жеңілдету, оқу материалдарын тиімді пайдалану және тест тапсырмаларын дайындау процесін автоматтандыру.

## 🚀 Негізгі мүмкіндіктер

- **Құжаттарды жүктеу:** Бірнеше PDF және TXT файлдарын жүктеп, олардың мәтінін автоматты түрде алу.
- **Мәтінді өңдеу:** Құжаттардан алынған мәтінді тазалау, артық бос орындарды жою және мәтінді бөлімдерге бөлу.
- **Тақырыптарды анықтау:** Google Gemini AI көмегімен оқу материалының негізгі бөлімдері мен тақырыптарын анықтау.
- **5 қиындық деңгейі:** 1 (Өте жеңіл) деңгейінен 5 (Өте қиын) деңгейіне дейін сұрақтар құрастыру.
- **Тест сұрақтары:** A, B, C, D жауап нұсқалары бар тест тапсырмаларын генерациялау.
- **Ашық сұрақтар:** Оқу материалы негізінде еркін жауап беруді талап ететін сұрақтар құрастыру.
- **Интерактивті тестілеу:** Пайдаланушының жауаптарын тексеру, дұрыс жауаптарды және түсіндірмелерді көрсету.
- **AI сапа бағалауы:** Пайдаланушы жауаптарының сапасын жасанды интеллект көмегімен талдау.
- **Дерекқор (SQLite):** Құрастырылған сұрақтарды сақтау, қарау, өңдеу және өшіру.
- **Деректерді экспорттау:** Сұрақтарды JSON, CSV және Excel форматтарында жүктеп алу.

## 🛠️ Қолданылатын технологиялар

| Технология | Қолданылуы |
|---|---|
| Python | Негізгі бағдарламалау тілі |
| Streamlit | Веб-қосымшаның интерфейсі |
| Google Gemini AI | Сұрақтарды генерациялау және жауаптарды бағалау |
| PyMuPDF | PDF файлдарынан мәтін алу |
| SQLite | Сұрақтарды сақтау |
| Pandas | Деректерді өңдеу |
| OpenPyXL | Excel файлдарын экспорттау |

## 📂 Жобаның құрылымы

```text
ai-surak-generator/
│
├── app.py
├── ai_engine.py
├── doc_processor.py
├── database.py
├── questions.db
├── requirements.txt
├── README.md
└── .gitignore
```

**Негізгі файлдардың сипаттамасы:**

- `app.py` — қосымшаның негізгі файлы және пайдаланушы интерфейсі.
- `ai_engine.py` — жасанды интеллект арқылы сұрақтарды генерациялау және жауаптарды бағалау.
- `doc_processor.py` — PDF және TXT құжаттарынан мәтін алу, тазалау және өңдеу.
- `database.py` — SQLite дерекқорымен жұмыс істеу және деректерді экспорттау.
- `questions.db` — сұрақтар сақталатын дерекқор.
- `requirements.txt` — қажетті Python кітапханалары.

## ⚙️ Орнату және іске қосу нұсқаулығы

### 1. Репозиторийді жүктеп алу

```bash
git clone <сіздің-github-сілтемеңіз>
cd ai-surak-generator
```

### 2. Виртуалды орта құру

```bash
python -m venv venv
```

Windows жүйесінде виртуалды ортаны іске қосу:

```bash
venv\Scripts\activate
```

### 3. Қажетті кітапханаларды орнату

```bash
pip install -r requirements.txt
```

### 4. Google Gemini API кілтін баптау

Google Gemini API кілтін Google AI Studio платформасынан алуға болады:

https://aistudio.google.com/

API кілтін жобада қауіпсіз түрде сақтау қажет. Оны GitHub-қа жарияламаңыз.

### 5. Қосымшаны іске қосу

```bash
streamlit run app.py
```

Осы командадан кейін веб-қосымша браузерде ашылады.

## 📊 Деректер базасы және экспорттау

Жоба сұрақтарды сақтау үшін SQLite дерекқорын пайдаланады.

Дерекқорда келесі ақпараттар сақталады:

- Құжат атауы;
- Тақырып;
- Қиындық деңгейі;
- Сұрақ түрі;
- Сұрақ мәтіні;
- Жауап нұсқалары;
- Дұрыс жауап;
- Түсіндірме.

Сақталған сұрақтарды үш форматта экспорттауға болады:

| Формат | Сипаттамасы |
|---|---|
| JSON | Құрылымдалған деректерді сақтау |
| CSV | Кестелік деректермен жұмыс істеу |
| Excel | Сұрақтарды қарау және талдау |

## 🧪 Жүйені тестілеу

Қосымшаның жұмысын тексеру үшін PDF және TXT форматындағы оқу материалдарын пайдалануға болады.

Тестілеу кезеңдері:

1. Оқу материалын жүктеу.
2. Құжаттан мәтін алу.
3. Мәтінді тазалау және бөлімдерге бөлу.
4. Негізгі тақырыптарды анықтау.
5. Әртүрлі қиындық деңгейлерінде сұрақтар генерациялау.
6. Тест сұрақтарына жауап беру.
7. Жауаптарды тексеру және нәтижелерді бағалау.
8. Сұрақтарды дерекқорға сақтау.
9. CSV және Excel форматтарында экспорттау.
